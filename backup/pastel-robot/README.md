# Pastel robot (backup)

Snapshot of the first robot (pastel lavender/blue, sits and learns to stand up), kept as it was
before the white-and-pink robot replaced it on the main page. It is a self-contained copy: nothing
here imports from the main `src/`, so later changes there don't affect it.

- Dev: `npm run dev`, then open `/backup/pastel-robot/`
- Production: built alongside the main page (see `vite.config.js`) and served at `/backup/pastel-robot/`
