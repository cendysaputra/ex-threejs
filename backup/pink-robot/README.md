# White-and-pink robot (backup)

Snapshot of the white-and-pink robot (stands and waves with its raised hand), kept as it was when
the pastel robot went back on the main page. It is a self-contained copy: nothing here imports from
the main `src/`, so later changes there don't affect it.

- Dev: `npm run dev`, then open `/backup/pink-robot/`
- Production: built alongside the main page (see `vite.config.js`) and served at `/backup/pink-robot/`
